# 供应商编辑与 Agent 接入布局修订

范围：用户反馈旧分栏不便编辑，要求重排供应商与 Agent 接入，并参考 Codex 的深浅色、增加少量模糊。本轮不改后端协议、凭据存储、调度或自动分配规则。

## BF-LAYOUT-01：供应商编辑空间不足

- E-1：用户截图显示大统计卡、固定列表和可单独滚动的详情占用主要空间，编辑入口藏在详情顶部。
- 变更：紧凑统计、全宽连接卡片、行内操作、同页展开详情；移除固定详情滚动区。名称可直接打开宽编辑器，连接和模型并排。
- Key：复用按标识保存的 Key 管理组件，提供嵌入模式，避免 form 嵌套；保存 Key 独立于连接表单，Esc 先取消 Key 输入。
- 验证 E-2：[V] 1180×720 深色编辑器已查看；浏览器实测无 form 嵌套、空 Key 回车不误提交连接，Esc 后连接对话框仍保留。
- 验证 E-3：[V] 960×640 浅色编辑器完整显示连接、模型与底部按钮；对话框宽 912px、高约 583px，没有超出视口。Key 输入与连接表单无嵌套。
- 验证 E-4：[V] 单元回归覆盖保存 Key、Esc 取消、忙碌时回车不再写入；Key 与连接草稿保留，等待现有操作完成后可重试。连接和 Key 的键盘提交均遵守忙碌状态。
- 验证 E-6：[V] 构建后的 Windows 原生实例加载真实的 3 个 RoseAI 连接，打开宽表单可同时查看连接、Key 和 4 个模型；查看后取消，未保存任何连接或凭据变更。

## BF-LAYOUT-02：接入开关与动作混排

- 变更：全宽 Agent 卡片；名称、状态、接入开关在标题行，默认模型与启停、配置在下方；未接入条目直接可见。
- 保留：模型选择、启停、历史选择重置、供应商范围、Claude 档位及断开预览的原有行为。
- 验证 E-5：[V] 浏览器已查看 1180×720 深色卡片、960×640 浅色 Claude 档位展开；开关、默认模型、配置按钮分区，未接入条目可见。
- 验证 E-7：[V] Windows 原生深色 Agent 页面加载完整的未接入列表，开关、默认模型、配置入口正常显示；未改变接入开关或模型选择。

## 外观

- 白灰 / 炭灰中性色，主按钮采用黑白对比，品牌图标保留原色。
- 背景层使用少量 backdrop blur；文字和表单不应用 filter。
- 弹层与页面滚动区区分；提供减少透明度和减少动画的样式。
